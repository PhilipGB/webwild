# Asset provenance and usage

The original procedural low-poly `.glb` meshes and `.svg` UI illustrations, maps and boards in this package are created specifically for this handoff, as are the generated concept images. They may be used and modified for the Webwild game project. No third-party web image downloads, game music or paid marketplace assets are bundled.

These are not trademark clearances or guarantees that any chosen external material is safe to reuse. The agent is responsible for checking/licensing any added third-party material and documenting author, URL, license and modifications. Do not sell or describe concept PNGs as actual Godot screenshots.

Expanded original 3D meshes generated procedurally for this handoff are included for direct use and modification in the Webwild project. Generated GLB and contact sheet previews are project assets. No third-party model files are included.
