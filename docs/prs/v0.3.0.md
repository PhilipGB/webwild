## P0 — Scalable world contracts, persistence foundation

Status: **DONE** (no new terrain yet, by design).

Delivered on `feat/v0.3-p0-world-foundations`:

- `src/Core/WorldCoordinates.cs` — signed 64-bit `ChunkCoordinate` (24 m chunks,
  13-point 2 m terrain grid), `WorldPos` (chunk + local doubles, floor
  semantics symmetric across zero), `WorldOrigin` origin rebasing.
- `src/Core/TerrainSampler.cs` — seeded coordinate-based value noise
  (`DeterministicHash`, SplitMix64) that is continuous across chunk boundaries
  and identical on regeneration.
- `src/Core/ChunkData.cs` — engine-free chunk payload (height grid, prop
  placements) with a bit-exact `ContentHash()`.
- `src/Core/LandmarkCatalog.cs` — constant authored-landmark origins
  (garden at world origin; Reedwater at (96, 0, 0)); these are a save contract.
- `src/Core/WorldManifest.cs` — world-manifest schema 4 (seed, player `WorldPos`,
  landmark visits, exploration record, embedded schema-3 colony payload) plus
  versioned `ChunkChangeSave` records (built webs, food state, markers).
- `src/Core/WorldSaveStore.cs` — durable manifest + per-chunk files with
  atomic writes, `.bak` rotation, interrupted-temp-file cleanup and
  corrupt-record tolerance (regeneratable baseline is never saved).
- `src/Core/WorldSaveMigrator.cs` — legacy schema 1–3 → manifest wrapping with
  exactly one semantic change (player position becomes a world position);
  reverse extraction restores the established simulation load path.
- `docs/adr/0001-never-ending-world.md` — decision record covering world
  coordinates, chunk identity, determinism, landmarks, streaming, saves,
  navigation, off-screen simulation, regeneration and migration.
